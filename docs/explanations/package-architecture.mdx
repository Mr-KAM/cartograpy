# Architecture du package

Le package suit un flux logique.

1. acquisition ou lecture des données
2. préparation et transformation
3. rendu cartographique
4. export et organisation du projet

## Modules pivots

- `data`
- `processing`
- `mapper`
- `styling`
- `project`

## But de cette page

Expliquer quand utiliser une fonction simple, quand passer à `VectorTools` ou `RasterTools`, et quand structurer le travail avec `Project`.
