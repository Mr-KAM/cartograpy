# Installation

Cette page présente le parcours d'installation recommandé pour utiliser cartograpy en local.

## Pré-requis

- Python 3.11 ou supérieur
- Un environnement virtuel dédié
- Les dépendances système requises par geopandas, rasterio et cartopy selon votre plateforme

## Installation rapide

```bash
pip install cartograpy
```

## Installation pour le développement

```bash
pip install -e .[dev]
```

## Dépendances importantes

- `geopandas` pour les données vectorielles
- `rasterio` pour les rasters
- `cartopy` et `matplotlib` pour les cartes statiques
- `folium` ou `geemap` selon les usages web et notebook
