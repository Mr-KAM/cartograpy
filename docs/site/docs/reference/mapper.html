Organisation

cartograpy.mapper est un sous-package, un fichier par classe :

Fichier Contenu
helpers.py read_image, plot_choropleth
map.py Map — la classe principale, cartes statiques matplotlib/cartopy
map2d.py Map2D (hérite de Map) — cartes sans projection cartographique
webmap.py WebMap — cartes interactives Folium/Leaflet
situation.py SituationMap — carte + mini-carte de localisation

Tout reste importable depuis cartograpy.mapper directement (from cartograpy.mapper import Map).

Map concentre encore la majorité de la logique (création, couches, légende, échelle, flèche du nord, export…) dans une seule classe volumineuse — un découpage interne en mixins thématiques n’a pas encore été fait.

Constructeur de Map

Map(figsize=(12, 8), title="Carte", projection=ccrs.PlateCarree(),
    data_crs="EPSG:4326", dpi=300, verbose=True, basemap=True)
  • figsize (tuple, str ou dict, défaut (12, 8)) : taille en pouces, format papier ("A4", "A3"…) ou {"paper": ..., "orientation": ...}.
  • title (str, défaut "Carte") : titre de la carte.
  • projection (cartopy.crs, défaut ccrs.PlateCarree()) : projection cartographique de l’axe.
  • data_crs (str, défaut "EPSG:4326") : CRS supposé des données ajoutées.
  • dpi (int, défaut 300) : résolution de la figure.
  • verbose (bool, défaut True) : afficher les messages d’information.
  • basemap (bool, défaut True) : ajouter automatiquement côtes et frontières (cfeature.BORDERS, coastlines). Mettre False pour une carte vierge — garde la projection cartopy (donc add_north_arrow/add_scale_bar/add_inset_map restent utilisables), contrairement à Map2D qui abandonne la projection cartopy entièrement.
# Carte sans côtes ni frontières automatiques, mais avec projection cartopy
m = Map(title="Carte vierge", basemap=False)
m.add_polygons(mon_gdf, facecolor="lightyellow")
m.add_north_arrow()
m.show()

Note

Mode style="svg" : les 17 icônes embarquées ont des résolutions natives très différentes une fois rastérisées (de 5x16 à 580x580 px selon l’icône). Elles sont automatiquement ramenées à une taille de référence commune avant d’appliquer zoom — zoom=1 donne donc une taille cohérente quelle que soit l’icône choisie, plutôt que de dépendre de la résolution brute du fichier SVG. add_scale_bar(length=None, location='lower left', linewidth=2, units='km', color='black', fontsize=11, pad=0.1, alpha=1, label=None, style='auto', box_color='white', box_alpha=0.8, scale_loc='bottom', label_loc='top', add_as_layer=True, bar_style='boxes', major_div=None, minor_div=None, size=None, bar=None, labels=None, text=None, to='ax', position=(0.05, 0.05), aob=None, font=None, **kwargs)
set_scale_bar(**kwargs)

Ajoute une barre d’échelle sur la carte / modifie celle déjà créée. major_div/minor_div : None par défaut (calcul automatique par matplotlib-map-utils) — ne les fixer qu’ensemble avec un major_mult (via le dict bar=...), sinon le calcul de la barre échoue. to (défaut "ax") : "fig" ancre la barre à la figure entière plutôt qu’à l’axe carte (modes map-utils/scalebar uniquement — avertissement et retour à l’axe en mode manual, intrinsèquement géographique), même convention que add_north_arrow(..., to=...). position : point d’ancrage exact en coordonnées figure (0-1), utilisé uniquement si to="fig" — location détermine toujours quel coin de la barre touche ce point.

Note

font (FontProperties, ex. via google_font()) : matplotlib-map-utils ne supporte qu’une famille CSS générique ("serif", "sans-serif", "cursive", "fantasy", "monospace"), pas une police précise. Si le style résolu est map-utils ("auto", "ticks", "boxes") et font est fourni, bascule automatiquement vers style="scalebar" (avec avertissement) pour l’appliquer réellement. Fonctionne nativement en modes "scalebar" et "manual".

add_inset_map(data=None, on=None, mode='bbox', zoom_to_on=False, position=(0.65, 0.02, 0.33, 0.33), to='ax', circular=False, facecolor='white', edgecolor='black', linewidth=1.5, alpha=0.9, box_color='red', box_linewidth=2, land_color='lightgray', ocean_color='lightblue', projection=None, style='auto', location='lower right', size=None, pad=None, coords=None, transform=None, global_view=True, extent=None, indicator='extent', indicator_facecolor='red', indicator_linecolor='red', indicator_alpha=0.5, indicator_linewidth=1, indicator_straighten=True, indicator_pad=0.05, connector_color='black', connector_width=1, inset_size=None, zorder=99, show_borders=True, show_coastlines=True, **kwargs)
set_inset(**kwargs)

Ajoute une mini-carte de situation (inset map) montrant la zone étudiée dans son contexte / modifie celle déjà créée.

  • data (list[float] | GeoDataFrame, optionnel) : zone à surligner sur l’inset — bbox [minx, miny, maxx, maxy] ou GeoDataFrame. None (défaut) : reprend self.bounds, indicateur calculé depuis l’étendue actuelle de la carte principale (comportement hérité).
  • on (GeoDataFrame | list, optionnel) : couche(s) de contexte dessinée(s) sur l’inset (ex. tous les pays d’un continent, pour situer data dedans). GeoDataFrame unique ou liste de {"data": gdf, "kwargs": {...}}.
  • mode (str, défaut "bbox") : comment dessiner data quand c’est un GeoDataFrame — "bbox" (rectangle de son étendue) ou "geometry" (sa géométrie réelle). Sans effet si data est déjà une bbox.
  • zoom_to_on (bool, défaut False) : si True, zoome l’inset sur l’étendue totale de on (au lieu de la vue globale) et l’encadre d’un rectangle (box_color/box_linewidth). Sans effet si on n’est pas fourni (avertissement). Prioritaire sur global_view/extent.
  • to (str, défaut "ax") : ancre du positionnement — "ax" : position (mode classique) ou location/coords (mode map-utils) relatifs à l’axe de la carte principale. "fig" : relatifs à la figure entière. Même convention que add_north_arrow(..., to=...).
  • circular (bool, défaut False) : si True, découpe l’inset en cercle plutôt qu’en rectangle (Axes.set_boundary), avec correction d’aspect pour un vrai cercle même si l’inset n’est pas physiquement carré (size ou position non carrés).
m.add_inset_map(on=bound.get_continent("Africa"), zoom_to_on=True, circular=True)
from cartograpy.data import Bound

bound = Bound()
m.add_inset_map(
    data=bound.get_country("Côte d'Ivoire"), mode="geometry",
    on=bound.get_continent("Africa"), zoom_to_on=True,
)
Avertissement

data valide un GeoDataFrame/GeoSeries ou une bbox de 4 éléments — tout autre type (ex. passer par erreur un GeoDataFrame là où l’ancienne API attendait une bbox bounds=) lève un TypeError explicite plutôt que d’être ignoré silencieusement ou de planter plus loin avec une erreur confuse.
