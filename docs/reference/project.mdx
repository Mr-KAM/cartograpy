# Reference project

Le module `project` fournit un conteneur léger pour organiser un projet cartographique autour d'un répertoire racine, d'un dossier de données et d'un dossier de sortie.

## Exports publics

- `Project`
- `init_project`
- `VECTOR_EXTENSIONS`
- `RASTER_EXTENSIONS`
- `TABULAR_EXTENSIONS`
- `SHAPEFILE_SIDECARS`
- `TAB_SIDECARS`

## Classe Project

### Constructeur

```python
Project(path=None, data_dir="data", output_dir="output", crs="EPSG:4326")
```

### Paramètres

- `path` : répertoire racine du projet. Si `None`, le répertoire courant est utilisé.
- `data_dir` : nom du dossier qui stocke les données.
- `output_dir` : nom du dossier qui stocke les sorties.
- `crs` : système de coordonnées de référence du projet.

### Attributs principaux

- `path` : chemin absolu du projet
- `data_dir` : chemin absolu du dossier de données
- `output_dir` : chemin absolu du dossier de sortie
- `crs` : objet `pyproj.CRS`
- `vector_files` : liste des fichiers vectoriels classés
- `raster_files` : liste des fichiers raster classés
- `tabular_files` : liste des fichiers tabulaires classés

## Méthodes

### `init()`

Crée les dossiers `data/` et `output/` si nécessaire et renvoie le chemin du projet.

```python
project = Project("./mon_projet")
project.init()
```

### `available_crs(auth_name="EPSG", crs_type=None, contains="")`

Méthode statique qui interroge les CRS disponibles via `pyproj.database.query_crs_info`.

```python
Project.available_crs(contains="UTM")
```

Retour attendu : une liste de dictionnaires contenant au minimum l'autorité, le code, le nom, le type et la zone d'usage.

### `add_data(data, file_extension=None, filename="output", timestamp=False, raster_meta=None)`

Enregistre un jeu de données directement dans le dossier `data/` du projet en réutilisant `cartograpy.data.save`.
Accepte aussi un chemin vers un fichier existant : le fichier est copié et ses sidecars (.shx, .dbf, .prj, etc.) sont copiés automatiquement pour les shapefiles.

```python
# Depuis un objet en mémoire
project.add_data(gdf, "geojson", filename="limites")

# Depuis un chemin de fichier (extension déduite automatiquement)
project.add_data("../source/carte.shp")
```

Paramètres importants :

- `data` : `GeoDataFrame`, `DataFrame`, raster ouvert, tableau raster, ou chemin (`str`/`Path`) vers un fichier
- `file_extension` : extension cible. Optionnel si `data` est un chemin (déduit depuis le fichier source)
- `filename` : nom de base du fichier dans le dossier `data/`
- `timestamp` : ajoute un suffixe temporel au nom si activé
- `raster_meta` : métadonnées raster requises si la source est un tableau NumPy

Particularité : les fichiers sidecars shapefile (.shx, .dbf, .prj, .cpg, etc.) sont copiés automatiquement.

### `organize_project()`

Répartit automatiquement les fichiers du dossier `data/` dans trois sous-dossiers selon leurs extensions.

- `vector/`
- `raster/`
- `tabular/`

La méthode met aussi à jour les listes `vector_files`, `raster_files` et `tabular_files`.

```python
project.organize_project()
```

### `list_data(type_filter=None)`

Liste les fichiers présents dans le dossier `data/` du projet.

```python
# Tous les fichiers
project.list_data()

# Seulement les fichiers vectoriels
project.list_data(type_filter="vector")
```

Retour attendu : une liste de dictionnaires contenant `name`, `extension`, `type`, `size`, `path` et `relative_path`.

### `load_data(name, layer=None)`

Charge un fichier depuis le dossier `data/` du projet via `cartograpy.data.load`. Le fichier est recherché par nom exact ou par nom de base (sans extension).

```python
gdf = project.load_data("regions_civ.geojson")
# ou simplement par nom de base
gdf = project.load_data("regions_civ")
```

### `remove_data(name)`

Supprime un fichier (et ses sidecars shapefile/tab) du dossier `data/`.

```python
project.remove_data("carte.shp")  # supprime aussi .shx, .dbf, .prj, .cpg…
```

### `get_path(name, folder="data")`

Retourne le chemin absolu d'un fichier dans le projet. Cherche dans `data/` par défaut, ou dans `output/`.

```python
path = project.get_path("regions_civ.geojson")
path = project.get_path("carte_finale.png", folder="output")
```

### `set_crs(crs)`

Change le CRS du projet.

```python
project.set_crs("EPSG:32630")  # UTM zone 30N
```

### `clean_output()`

Supprime tous les fichiers et sous-dossiers du dossier `output/`.

```python
project.clean_output()
```

### `validate()`

Vérifie l'intégrité du projet : existence des dossiers, lisibilité des fichiers, présence des sidecars obligatoires (.shx, .dbf) pour chaque shapefile.

```python
report = project.validate()
# report["valid"] → True/False
# report["warnings"] → liste d'avertissements
# report["errors"] → liste d'erreurs
```

## Fonction utilitaire `init_project(path=None)`

Raccourci pour créer un projet avec la configuration par défaut puis lancer `init()` immédiatement.

```python
from cartograpy.project import init_project

init_project("./mon_projet")
```

## Constantes

### `VECTOR_EXTENSIONS`

Extensions reconnues comme données vectorielles pour le classement automatique.

### `RASTER_EXTENSIONS`

Extensions reconnues comme données raster.

### `TABULAR_EXTENSIONS`

Extensions reconnues comme données tabulaires.

### `SHAPEFILE_SIDECARS`

Extensions des fichiers compagnons d'un shapefile (.shx, .dbf, .prj, .cpg, .sbn, .sbx, .qix).

### `TAB_SIDECARS`

Extensions des fichiers compagnons d'un fichier MapInfo TAB (.dat, .map, .id).

## Exemple complet

```python
from cartograpy.project import Project

project = Project(path="./mon_projet", crs="EPSG:4326")
project.init()

# Ajouter un shapefile (avec ses sidecars)
project.add_data("../source/gadm41_CIV.shp")

# Lister les fichiers
project.list_data()

# Charger les données
gdf = project.load_data("gadm41_CIV")

# Organiser en sous-dossiers
project.organize_project()

# Vérifier l'intégrité
project.validate()

# Informations du projet
project.infos()
```

## Limites actuelles

- la structure de projet reste volontairement simple
- le classement automatique dépend uniquement des extensions
