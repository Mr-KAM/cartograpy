# Vue d'ensemble de l'API

Les exports publics sont centralisés dans `cartograpy.__init__`.

## Modules publics

- `data`
- `processing`
- `mapper`
- `styling`
- `project`
- `converter`
- `iso_code`

## Objets majeurs

- `Map`, `Map2D`, `WebMap`, `SituationMap`
- `GeoBoundaries`, `Bound`, `OSM`, `Hydro`, `DEM`, `WorldBank`
- `VectorTools`, `RasterTools`
- `Project`

## Recommandation

Chaque page de référence doit lister les signatures, paramètres, retours, erreurs courantes et exemples courts.
