# Cartes web

`WebMap` couvre les usages interactifs légers à partir de GeoDataFrame.

## Sujets à documenter

- création d'une carte centrée
- ajout de couches vectorielles
- colonnes de tooltip et popup
- ajout de marqueurs simples
- activation des contrôles de couche
- sauvegarde en HTML

## Limites à expliciter

- différences de capacités par rapport à `Map`
- dépendances web sous-jacentes
- tailles de jeux de données adaptées à ce mode de rendu
