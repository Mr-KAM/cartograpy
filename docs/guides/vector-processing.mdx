# Traitements vectoriels

Le module `processing` expose une API en deux niveaux.

- des fonctions simples pour les opérations fréquentes
- la classe `VectorTools` pour les workflows plus avancés

## Fonctions rapides

- `centroids`
- `join`
- `fusion`
- `add_column`
- `split_multipolygon`

## Familles de méthodes de `VectorTools`

- qualité et validité géométrique
- projection et structure attributaire
- sélection, découpe et extraction
- agrégation et jointures spatiales
- analyse de distances et voisinages
- interpolation, réseaux et autocorrélation spatiale

## Priorités de documentation

1. opérations de base testées
2. transformations géométriques fréquentes
3. export et chaînage de méthodes
