# OSM et sources en ligne

Cartograpy embarque plusieurs clients orientés téléchargement de données.

## Sources couvertes

- `OSM` pour les données OpenStreetMap
- `Hydro` pour les couches hydrographiques
- `DEM` pour les modèles numériques de terrain
- `WorldBank` pour les indicateurs tabulaires

## Ce que la page doit montrer

- requêtes par lieu et tags OSM
- téléchargement de limites et de couches hydro
- récupération d'un raster d'altitude
- extraction de données tabulaires par pays et période

## À expliciter

- limites de quotas ou de service
- temps d'attente et cache éventuel
- dépendances optionnelles et accès internet obligatoire
